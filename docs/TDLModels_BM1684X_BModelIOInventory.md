# TDL Models BM1684X BModel 输入输出规格实测清单

本文档由 BM1684X 边缘盒子 `10.56.30.33` 上的工具实测生成。模型已上传到设备目录 `/data/tdl_models/bm1684x`。

## 验证环境

- 设备：BM1684X SoC，Linux `5.4.217-bm1684`，aarch64
- `bmrt_test`: `/opt/sophon/libsophon-0.5.1/bin/bmrt_test`
- `tpu_model`: `/opt/sophon/libsophon-0.5.1/bin/tpu_model`
- 静态输入输出规格日志：`docs/tdl_model_logs/tpu_model_info_all.log`
- 运行验证日志：`docs/tdl_model_logs/bmrt_test_all.log`
- 运行验证汇总：`docs/tdl_model_logs/bmrt_test_summary.tsv`

## 验证结论

- 共解析 `65` 个 BM1684X bmodel。
- `bmrt_test --loopnum 1` 运行结果：`65` 个 OK，`0` 个失败。
- 所有模型都是静态 bmodel，均为 `stage=0`，`core num=1`。
- 输入 shape 和 dtype 差异很大，后续 sophon-stream TDL 插件不能硬编码一种固定输入规格。

## 对 sophon-stream TDL 插件设计的影响

1. 图像类模型大多使用 `uint8` 或 `int8` 输入，但 shape 从小尺寸裁剪图到 `1x3x896x896` 都存在；插件应读取 TDL SDK 模型配置或运行时参数，不应写死固定尺寸。
2. YOLO/PPYOLOE 检测模型暴露的是 raw head 输出，不是已经解码好的检测框；因此应使用 TDL SDK 的后处理能力，而不是复用 `yolo8-test` 的后处理代码。
3. 部分模型不是直接图像输入，例如 `1x42` 关键点向量、`1x77` 文本 token、音频特征，以及 tracking 的双输入模型。
4. 第一阶段插件建议优先支持整帧图像任务：`TDL_Detection`、`TDL_FaceDetection`、`TDL_SemanticSegmentation`、`TDL_InstanceSegmentation`、`TDL_LaneDetection`。
